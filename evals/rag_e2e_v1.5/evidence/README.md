# rag_e2e_v1.4 evidence bundle

Byte-for-byte copies of the documents behind the frozen rag_e2e_v1.4 dataset and the W retrieval
variant, plus retrieval fixtures for the no-model regression test
`tests/test_rag_e2e_v14_frozen.py`. Source paths are relative to the main checkout's untracked
`work/` tree. File paths quoted inside the documents also refer to that `work/` tree, which is
not in git.

| file | what it is | source under `work/` |
|---|---|---|
| `round1/RECOMMENDATION.md` | round-1 candidate-miss recommendation (no PREREG in round 1) | `agent_design/candidate_miss/RECOMMENDATION.md` |
| `round1/VERIFICATION.md` | independent re-verification of round 1 | `agent_design/candidate_miss/VERIFICATION.md` |
| `round2/PREREG.md`, `PREREG.sha256` | round-2 preregistration and its hash | `agent_design/candidate_miss/round2/` |
| `round2/SUMMARY.md` | round-2 results summary | same |
| `round2/DEVIATIONS.md` | deviations from the PREREG | same |
| `round2/README.md` | round-2 working notes | same |
| `round2/v14_frozen_rerun.md` | rerun of round 2 on the frozen v1.4 mapping | same |
| `round2/resolved_clauses.json`, `.sha256` | hand-resolved clauses (Part C ceiling) and hash | same |
| `answers_w/VERDICT.md` | verdict of the W answer runs | `agent_design/candidate_miss/answers_w/` |
| `answers_w/answers_w_report.md` | W answer-run report | same |
| `answers_w/ledger.json` | run ledger | same |
| `gold_proposal/PROPOSAL.md` | gold-audit proposal behind the v1.4 alternatives | `rag_e2e_v1.4/proposal/PROPOSAL.md` |
| `fixtures/retrieval_v14.json` | P0 and W final chunk lists per case, context budget, expected counts | generated by `tools/build_fixtures.py` |
| `tools/build_fixtures.py` | fixture generator (runs only against the main checkout's `work/`) | new |
| `MANIFEST.sha256` | sha256 of every file here except itself | new |

`round2/resolved_clauses.sha256` was written with a CRLF line ending; it is kept byte-for-byte,
so check it with `tr -d '\r' < resolved_clauses.sha256 | sha256sum -c`.

This folder is frozen. Do not edit it; any change goes into a new version folder.
